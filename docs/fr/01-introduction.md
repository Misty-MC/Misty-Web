Misty est un launcher gratuit pour **Minecraft : Java Edition** sur Windows. Il télécharge le jeu depuis les serveurs officiels de Mojang, gère tes profils et tes mods, et lance Minecraft avec les bons réglages. Il est écrit en [Rust](https://www.rust-lang.org/) avec une interface [Slint](https://slint.dev) : un seul fichier `Misty.exe`, rien d'autre à installer.

## En une minute

- **Toutes les versions.** Les releases et, sur demande, les snapshots, bêtas, alphas et versions Indev.
- **Des mod loaders en un clic.** Forge, NeoForge, Fabric, Quilt, OptiFine et LiteLoader, proposés seulement s'ils existent pour la version choisie. Voir [Versions et mod loaders](/docs/versions-and-loaders).
- **Des profils.** Chaque profil a sa version, son mod loader et son dossier de jeu, tandis que les gros fichiers restent partagés. Voir [Profils](/docs/profiles).
- **Des mods Modrinth et CurseForge.** Recherche, installation avec les dépendances, activation et désactivation. Voir [Mods, packs et shaders](/docs/mods-and-content).
- **Des modpacks.** Les modpacks Modrinth (`.mrpack`) et CurseForge deviennent un profil prêt à jouer. Voir [Modpacks](/docs/modpacks).
- **Skin et capes.** Change-les directement depuis le launcher, avec un aperçu en 3D. Voir [Skin et capes](/docs/skins).
- **Éditeur de packs de textures** (expérimental). Dessine les textures pixel par pixel et exporte un pack de ressources. Voir [Éditeur de textures](/docs/texture-editor).
- **Léger.** Le launcher consomme très peu de mémoire : la RAM reste pour le jeu.

## Configuration requise

- Windows 10 ou 11, 64 bits.
- Une connexion Internet au premier lancement de chaque version (le jeu, les bibliothèques et Java sont téléchargés une seule fois).
- Un compte Microsoft qui possède Minecraft : Java Edition pour jouer en ligne. Les comptes hors-ligne sont aussi disponibles. Voir [Comptes](/docs/accounts).

Pas besoin d'installer Java : Misty télécharge auprès de Mojang la version de Java dont chaque version de Minecraft a besoin.

## Langues

L'interface existe en anglais, français, espagnol, italien et russe. L'anglais est la langue par défaut ; change-la dans les [Paramètres](/docs/settings), le changement s'applique tout de suite.

## Ce que Misty n'est pas

- **Pas un produit officiel.** Misty n'est pas affilié à Mojang Studios ni à Microsoft.
- **Pas un moyen d'avoir Minecraft gratuitement.** Misty ne contient aucun fichier du jeu. Pour jouer en ligne, il faut un compte qui possède le jeu.
- **Pas pour macOS ni Linux.** Misty est une application Windows.
