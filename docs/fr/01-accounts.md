Misty gère deux sortes de comptes. Tu choisis celui avec lequel jouer dans la liste **Compte** de l'accueil.

## Comptes Microsoft

Un compte Microsoft qui possède **Minecraft : Java Edition** est nécessaire pour rejoindre les serveurs en ligne et pour changer ton [skin et tes capes](/docs/skins).

1. Sur l'accueil, ouvre la liste **Compte** et choisis **Se connecter avec un compte Microsoft** (ou utilise la carte Compte Microsoft des [Paramètres](/docs/settings)).
2. Une fenêtre de connexion Microsoft s'ouvre. Connecte-toi comme sur le web.
3. Une fois connecté, le compte apparaît dans la liste avec la tête de ton skin.

Tu peux ajouter **plusieurs comptes Microsoft** et passer de l'un à l'autre depuis l'accueil ou les paramètres. **Oublier ce compte** retire un compte sans toucher aux autres.

> [!NOTE]
> **Déconnexion totale** oublie aussi le compte mis en cache sur ce PC. Utilise-la sur un ordinateur partagé.

### Si la connexion échoue

| Message | Que faire |
|---|---|
| *Ce compte Microsoft n'a pas de profil Xbox* | Connecte-toi une fois sur minecraft.net pour créer le profil. |
| *Xbox Live n'est pas disponible dans le pays de ce compte* | Le pays du compte ne permet pas Xbox Live. |
| *Ce compte doit d'abord être vérifié (âge) sur xbox.com* | Termine la vérification d'âge sur xbox.com. |
| *Ce compte est un compte enfant* | Un adulte doit l'ajouter à une famille Microsoft. |
| *Ce compte ne possède pas Minecraft Java Edition* | Achète le jeu, ou connecte le compte qui le possède. |

## Comptes hors-ligne

Les comptes hors-ligne sont des pseudos utilisables sans compte Microsoft. Gère-les dans la carte **Comptes hors-ligne** des [Paramètres](/docs/settings) : tape un pseudo et clique sur **Ajouter**.

Au premier lancement, Misty crée un compte hors-ligne appelé *Misty*.

> [!WARNING]
> Les serveurs qui vérifient les comptes (la plupart des serveurs publics) refusent les comptes hors-ligne. Ils servent pour le solo et pour les serveurs qui les acceptent.

## Où sont enregistrés les comptes

- Comptes Microsoft : `msa.json`
- Comptes hors-ligne : `listpseudo.txt`

Les deux sont dans `%LOCALAPPDATA%\Misty`. Voir [Fichiers et dossiers](/docs/files-and-folders).
