Misty is a free launcher for **Minecraft: Java Edition** on Windows. It downloads the game from Mojang's official servers, manages your profiles and mods, and starts Minecraft with the right settings. It is written in [Rust](https://www.rust-lang.org/) with a [Slint](https://slint.dev) interface: a single `Misty.exe` file, with nothing else to install.

## In one minute

- **Every version.** Releases, and on request snapshots, betas, alphas and Indev versions.
- **Mod loaders in one click.** Forge, NeoForge, Fabric, Quilt, OptiFine and LiteLoader, offered only when they exist for the version you pick. See [Versions and mod loaders](/docs/versions-and-loaders).
- **Profiles.** Each profile has its own version, mod loader and game folder, while the heavy files stay shared. See [Profiles](/docs/profiles).
- **Mods from Modrinth and CurseForge.** Search, install with their dependencies, enable or disable them. See [Mods, packs and shaders](/docs/mods-and-content).
- **Modpacks.** Modrinth `.mrpack` and CurseForge modpacks become a ready-to-play profile. See [Modpacks](/docs/modpacks).
- **Skin and capes.** Change them straight from the launcher, with a 3D preview. See [Skin and capes](/docs/skins).
- **Texture pack editor** (experimental). Draw textures pixel by pixel and export a resource pack. See [Texture pack editor](/docs/texture-editor).
- **Light.** The launcher itself uses very little memory, so the RAM goes to the game.

## Requirements

- Windows 10 or 11, 64-bit.
- An Internet connection for the first launch of each version (game files, libraries and Java are downloaded once).
- A Microsoft account that owns Minecraft: Java Edition to play online. Offline accounts are also available. See [Accounts](/docs/accounts).

Java does not need to be installed: Misty downloads the Java version each Minecraft version needs, from Mojang.

## Languages

The interface is available in English, French, Spanish, Italian and Russian. English is the default; change it in [Settings](/docs/settings), the change applies immediately.

## What Misty is not

- **Not an official product.** Misty is not affiliated with Mojang Studios or Microsoft.
- **Not a way to get Minecraft for free.** Misty ships no game files. To play online you need an account that owns the game.
- **Not for macOS or Linux.** Misty is a Windows application.
