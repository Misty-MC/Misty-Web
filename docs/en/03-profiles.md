A profile is a separate Minecraft setup, like an instance in other launchers. Each profile has:

- its own **version** and **mod loader**;
- its own **game folder**: `mods`, `resourcepacks`, `shaderpacks`, `saves` (worlds) and options.

Versions, libraries and assets stay **shared** between profiles: nothing is downloaded twice.

## Create a profile

1. Open **Profiles, mods and modpacks** in the sidebar.
2. Click **New profile**.
3. Give it a name, pick the version and the mod loader.
4. Click **Create profile**.

To start from a ready-made set of mods, use **Install a modpack** instead. See [Modpacks](/docs/modpacks).

## Play with a profile

Pick the profile in the **Profile** list of the home page, then click **Play**. *Quick play* uses the shared game folder, without a profile.

The profile list shows when each profile was last played (*Played today*, *Played yesterday*…).

## Manage a profile

Open a profile from the list to:

- see and manage its **Content**, or **Discover** new mods, packs and shaders. See [Mods, packs and shaders](/docs/mods-and-content);
- **Rename** it or **Change its icon**;
- **Open the profile folder** in the Windows Explorer.

To delete a profile, use the delete button in the profile list.

> [!WARNING]
> Deleting a profile permanently erases its mods, packs, worlds and settings.

## Where profiles live

Each profile is a folder in `%LOCALAPPDATA%\Misty\instances\`. See [Files and folders](/docs/files-and-folders).
